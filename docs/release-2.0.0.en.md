# FologneMusic 2.0.0

[Leia em português](release-2.0.0.md)

## What's new

- The **Downloads** tab accepts YouTube links from the **Share** menu or through the app. The queue shows progress and history and supports canceling and retrying. MP3 files are saved in `Music/FologneMusic`.
- **Recently added** shows files from the last 90 days, newest first.
- The playlist picker shows track artwork, adds tracks in selection order and uses a navy highlight while dragging.
- The **Previous** and **Next** controls follow the queue with one tap. The track menu can delete a file from the device after confirmation.
- The queue shows the shuffled playback order, supports reordering and restores the sequence when the app reopens.

## Installation

Download `FologneMusic-2.0.0.apk` under **Assets**, open it in the Android file manager and install or update FologneMusic. Playback requires Android 7.0 or later. **Downloads** requires Android 10 or later. The APK supports ARM64 and x86-64.
