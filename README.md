# MusicAPP

Aplicativo de música para Android com interface em Flutter e backend em Django.

## Funcionalidades planejadas

- Reprodução de músicas armazenadas no celular.
- Biblioteca com faixas, playlists, pastas e álbuns.
- Favoritos, histórico e reprodução em segundo plano.
- Player com abas Música, Letra e Significado.
- Pesquisa de letras e significados na internet, com armazenamento em JSON para consulta offline quando permitido pela fonte.
- Tema escuro com predominância de azul-marinho e preto.
